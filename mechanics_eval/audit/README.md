# Optional audit and human-review tools

These modules **inspect or verify saved RGB evidence**. They do not generate new benchmark verdicts, change the reference engine, or run during the normal `python -m mechanics_eval --model ...` pipeline.

| File | Purpose | CLI entry point |
|---|---|---|
| `reader.py` | Export a small image-labeling sheet; compare manually labeled counts/tiles to the RGB reader. Also provides the original `confusion` helper used for reference-engine validation. | `export-review`, `audit-reader` |
| `missing.py` | Diagnose UNKNOWN and missing-observation records from saved measurements and crops. | `audit-missing` |
| `pixels.py` | Strict independent RGB-patch translation check; may abstain. | Tested as a diagnostic helper; no public CLI |
| `human.py` | Export full interactive annotation workflows and summarize real reviewer labels, without altering scores. | `export-human-review`, `summarize-human-review` |
| `human_review.html` | Offline HTML template for `human.py`; kept alongside its exporter. | Generated by `export-human-review` |

All commands are dispatched through the existing public CLI from the TinyWMCraft repository root:

```bash
python -m mechanics_eval.cli export-human-review --help
python -m mechanics_eval.cli summarize-human-review --help
python -m mechanics_eval.cli audit-reader --help
python -m mechanics_eval.cli audit-missing --help
```

**Why keep human review?** The automated reader has outstanding independent generated-image verification. This workflow deliberately creates blank labels, requires reviewers to enter their judgments, and reports missing judgments explicitly. Opening a report does not constitute verification. The templates and modules are optional, but not obsolete.

Audits should write only to fresh paths under the gitignored `mechanics_eval/runs/`. If your previous notes or scripts imported individual files directly, use `mechanics_eval.audit.human`, `mechanics_eval.audit.reader`, `mechanics_eval.audit.missing`, and `mechanics_eval.audit.pixels` instead.
