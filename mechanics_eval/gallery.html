What these numbers mean

Scenario frequencies count PASS / total attempts per mechanic; FAIL and UNKNOWN remain separate. For atomic checks, PASS / eligible applies only when prerequisites allow evaluation, with NOT_TESTED shown explicitly. A 90% rate on ten controlled seeds is a descriptive 9/10, not a universal correctness guarantee. Each atomic measurement tests one mechanic. Only required stages affect scenario overall; unrelated diagnostics stay separate. A confirmed required failure wins over an unreadable fact.

UNKNOWN is undecided, not a failure or a success. Scenario decision coverage is (PASS + FAIL) / attempted. Atomic decision coverage uses eligible measurements; eligibility coverage is eligible / applicable. Failed or unknown prerequisites yield NOT_TESTED. NOT_APPLICABLE is excluded. Category success and coverage macros weight categories equally.

Dynamic entities, occlusion, corrupted HUD values and ambiguous localization limit observation. The new generated-image pose and identity readers still need independent labels, including the two seed-6 translation steps. Six conditional table-loss observations must not be described as ten object-deletion failures. This benchmark does not establish downstream RL performance or long-term global map consistency.
